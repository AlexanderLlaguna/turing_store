# Turing Store — Sprint 1

Proyecto orientado a la venta de accesorios informáticos.

## Estudiante

Wilson Llaguna

## Descripción

Turing Store presenta una selección de accesorios tecnológicos funcionales para estudiar, trabajar y crear. La primera versión se concentra en la identidad visual, la página de inicio y la navegación general del proyecto.

## Público objetivo

Estudiantes, docentes, trabajadores y usuarios que necesitan accesorios informáticos confiables y accesibles.

## Categorías iniciales

- Periféricos.
- Audio.
- Almacenamiento.
- Conectividad.

## Tecnologías utilizadas

- HTML5 semántico.
- CSS3.
- Bootstrap 5.3.
- JavaScript básico provisto por la plantilla.

## Estructura del proyecto

- `index.html`: página principal personalizada.
- `catalogo.html`: catálogo previsto para el Sprint 2.
- `producto.html`: detalle de producto previsto para el Sprint 2.
- `carrito.html`: carrito previsto para el Sprint 2.
- `perfil.html`: perfil previsto para el Sprint 3.
- `admin.html`: administración prevista para el Sprint 3.
- `css/styles.css`: identidad visual y estilos responsive.
- `js/base.js`: navegación, aviso de ingreso y modal de alcance.
- `assets/`: logotipo, favicon e imágenes SVG del proyecto.

## Ejecución

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir `index.html` con la extensión Live Server.
3. Probar la navegación y el menú responsive.

## Funcionalidades desarrolladas en el Sprint 1

- Identidad visual propia y logotipo de Turing Store.
- Hero principal con propuesta de valor.
- Cuatro productos destacados escritos directamente en HTML.
- Sección de beneficios.
- Navegación responsive entre páginas existentes.
- Footer con información del proyecto.
- Accesibilidad básica mediante HTML semántico, textos alternativos, contraste y foco visible.

## Funcionalidades pendientes

- Catálogo dinámico, búsqueda y filtros.
- Detalle dinámico de productos.
- Carrito y almacenamiento local.
- Registro e inicio de sesión.
- Firebase, pedidos y panel administrativo.

## Decisiones de diseño

Se eligió una estética minimalista basada en azul noche, blanco, gris claro y turquesa. Las tarjetas utilizan bordes suaves, espacios amplios y sombras discretas. El logotipo combina la letra T con nodos inspirados en circuitos electrónicos.
